# 后续待办工作清单 (TODO List)

## 1. 核心逻辑增强
- [ ] **RAG 增强**：目前 POI 检索是基于关键词的简单匹配，可以引入向量数据库（如 ChromaDB）实现基于语义的 POI 推荐。
- [ ] **多轮对话能力**：目前规划是一次性的，可以支持用户在 Explainer 环节通过对话微调方案（例如：“把第三天的午餐换成火锅”）。
- [ ] **更精细的评分权重**：支持用户在画像中自定义不同维度（预算、节奏、兴趣）的权重。

## 2. 数据与 API
- [ ] **美团/大众点评接入**：目前仅有高德 POI，缺乏真实的餐厅评分和人均消费数据。
- [ ] **天气预报联动**：Replanner 节点目前是 Mock 事件触发，可以接入真实天气 API，实现“预测到后天下雨自动触发重规划”。
- [ ] **酒店 API 接入**：目前酒店是 Mock 的，可以接入携程等 API 获取真实房价。

## 3. 前端体验优化
- [ ] **地图可视化**：在行程详情页引入高德地图 JS API，可视化展示每日路径。
- [ ] **移动端适配**：目前 UI 主要针对桌面端，黑客松演示时如果能用手机操作会更亮眼。
- [ ] **实时推送**：使用 WebSocket 实现后端 Agent 执行进度的实时展示（例如：当前正在进行“冲突分析”...）。

## 4. 稳定性与部署
- [ ] **并发处理**：目前后端 `_TRIPS` 是全局字典，多用户并发时可能存在线程安全问题。
- [ ] **持久化存储**：将 `_TRIPS` 和 `_PROFILES` 从内存迁移到数据库（如 SQLite 或 PostgreSQL）。
- [ ] **Docker 化**：编写 Dockerfile，实现一键部署。
